## Four-minute sequence

1. Show the Cloud Run URL, revision, and Swagger page.
2. Run the nutrition companion demo and show the profile saved in Firestore.
3. Resolve `N204` and explain the curated campus confidence boundary.
4. Generate the proactive multi-option fitness suggestion.
5. Ask a follow-up and show `source: stored_suggestion` and `gemini_called: false`.
6. Save the selected suggestion to Google Calendar.
7. Run the supplier demo to show PREPARE, REPLAN, and LEAVE behavior.
8. Run the self-evolution demo to show score, candidate proposal, and explicit promotion.
9. Show the event/evaluation records and Vertex AI request evidence.

## Evidence checklist

- Cloud Run service page proves Google Cloud deployment.
- Swagger response proves the live API is reachable.
- Vertex AI configuration or logs prove Gemini 3.5 Flash usage.
- Firestore profile and suggestion documents prove persistent personalization.
- Calendar event proves a lightweight external action.
- Gmail message proves proactive notification delivery.
- Evaluation run proves golden-case scoring.
- Proposal and policy records prove bounded self-evolution.
- Terminal output proves the automated test suite passes.

Claims must remain limited to implemented integrations. The project does not
claim university-portal, WhatsApp, banking, POS, printing, or device-density
integrations.
