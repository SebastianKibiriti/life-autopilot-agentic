# Known issues and missing information

- ADK and Gemini integration approach is not selected at code level.
- Firestore collection layout and security rules are not implemented.
- Authentication and student identity are not defined in the API.
- Timezone normalization, DST, and clock injection need a decision.
- Current location permissions and privacy retention need implementation.
- Route and Places failure/fallback thresholds need tests.
- Notification delivery, acknowledgement, retry, and idempotency are undefined in code.
- The autonomous trigger mechanism is undecided between scheduler, Pub/Sub, mobile background work, or a minimal hybrid.
- Timetable extraction schema and review UI are not implemented.
- Devpost registration and submission have not been completed.
