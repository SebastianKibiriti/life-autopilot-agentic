# Hackathon context

The project targets the All Things Agentic Hackathon and The Taskmaster category. The final build must visibly use Gemini 3.5+, a Google agent framework, and Google Cloud infrastructure. The intended stack is Gemini via Vertex AI, Google ADK, Cloud Run, and Firestore.
