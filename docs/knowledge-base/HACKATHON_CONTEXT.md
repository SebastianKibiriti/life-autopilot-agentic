# Hackathon context

The project targets the All Things Agentic Hackathon and The Collaborative Partner category. The final build must visibly use Gemini 3.5+, a Google agent framework, and Google Cloud infrastructure. The implementation uses `gemini-3.5-flash` via Vertex AI with the `global` location, the Google Gen AI SDK, Cloud Run, and Firestore for persistent personalization.
