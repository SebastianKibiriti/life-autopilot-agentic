# Fresh-build and reuse disclosure

## Repository origin

This repository was created as a fresh implementation for the All Things Agentic Hackathon. The historical Life Autopilot project predates this hackathon and is treated as product inspiration and prior architectural context only.

## Reused code

At the current baseline, no historical Life Autopilot source files have been copied into this repository. The backend and Flutter shell are new implementation files created for this rebuild.

## Reused concepts and references

The product definition, workflow, domain direction, and Google stack are based on the project roadmap and the maintenance prompt stored in this repository. Framework dependencies are declared in `backend/requirements.txt` and `mobile/pubspec.yaml`.

## Future disclosure rule

If historical code, third-party snippets, datasets, images, or generated assets are added:

1. Record the source and file path here.
2. Explain what was reused and why.
3. Record any license or permission constraint.
4. Mention the reuse in the final hackathon submission disclosure.
